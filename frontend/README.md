# MEBELCHI AI frontend

React 19 + TypeScript + Vite + Tailwind 4. See the root [README](../README.md) for the full project and
[docs/ARCHITECTURE.md](../docs/ARCHITECTURE.md) for the source layout.

```bash
npm install
npm run dev          # http://localhost:5173, /api proxied to :8000
npm test             # vitest
npx tsc -b && npm run build
```
